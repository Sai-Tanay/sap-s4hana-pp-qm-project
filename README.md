# sap-s4hana-pp-qm-project

# SAP S/4HANA PP & QM Manufacturing Process Simulation

## Project Overview

This is a self-directed portfolio project created to understand and document an end-to-end manufacturing process using SAP S/4HANA Production Planning (PP) and Quality Management (QM) concepts.

The project focuses on production planning, master data, MRP, production execution, and quality management.

## Business Scenario

A manufacturing business needs to produce finished product **FG-1000** based on planned demand and ensure that the manufactured product meets defined quality requirements.

## End-to-End Process

Material Master
→ BOM
→ Routing
→ Production Version
→ Demand
→ MRP
→ Production Order
→ Production Confirmation
→ Goods Receipt
→ Quality Inspection
→ Inspection Results
→ Usage Decision
