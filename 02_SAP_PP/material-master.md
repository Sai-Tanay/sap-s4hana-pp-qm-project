
# Material Master

## Objective

The material master contains the basic information required to plan, produce, store, and manage a manufactured product.

For this simulation, a simple finished product and its raw materials are defined to support the PP manufacturing process.

## Material Categories

| Material | Description | Category | Purpose |
|---|---|---|---|
| FG-1000 | Finished Product | Finished Good | Manufactured product |
| RM-1001 | Raw Material A | Raw Material | Component used in production |
| RM-1002 | Raw Material B | Raw Material | Component used in production |
| RM-1003 | Raw Material C | Raw Material | Component used in production |

## Planning-Relevant Information

The simulation considers the following material-related information:

- Material number
- Material description
- Material category
- Base unit of measure
- Procurement type
- Planning relevance
- Production relevance
- Storage information

## Manufacturing Scenario

The finished product **FG-1000** is manufactured using the following raw materials:

- RM-1001
- RM-1002
- RM-1003

These materials will later be connected to the Bill of Material (BOM), routing, production version, MRP, and production-order process.

## Scope Note

This document is part of a self-directed SAP S/4HANA PP & QM process simulation. The material data represents a project scenario created for learning and portfolio demonstration.
